# scribe-api

FastAPI backend for the Scribe AI documentation platform. Owns all MongoDB state and orchestrates calls to scribe-agents.

## Tech Stack

- Python 3.11+
- FastAPI + Pydantic v2
- Motor (async MongoDB driver)
- Swagger UI auto-generated at `/docs`
- Server-Sent Events (SSE) for live agent log streaming

## Running

```bash
cd scribe-api
PYTHONPATH=. .venv/bin/uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
```

Requires MongoDB at `mongodb://localhost:27017` and `.env` populated (see root CLAUDE.md).

Swagger UI: **http://localhost:8000/docs**

### Seed demo document

To insert a demo document for the first project in the database (useful for testing View Docs):

```bash
cd scribe-api
.venv/bin/python seed_doc.py
```

## API Endpoints

### Projects

| Method | Path | Description |
|---|---|---|
| GET | `/health` | Health + MongoDB ping |
| GET | `/api/v1/projects/` | List all projects (sorted newest first) |
| POST | `/api/v1/projects/` | Create project + trigger Phase 0 onboarding |
| GET | `/api/v1/projects/:id` | Get single project (includes feature_manifest) |
| PATCH | `/api/v1/projects/:id` | Update project fields (agents write back here) |
| DELETE | `/api/v1/projects/:id` | Delete project |
| POST | `/api/v1/projects/validate-repo` | Validate GitHub URL → branches list |
| POST | `/api/v1/projects/validate-confluence` | Validate Confluence space access |

### Sessions

| Method | Path | Description |
|---|---|---|
| POST | `/api/v1/sessions/generate` | Start Phase 1 — takes `{ project_id, depth, discovery_mode }` |
| GET | `/api/v1/sessions/project/:id` | List all sessions for a project |
| GET | `/api/v1/sessions/:id/stream` | **SSE** — replays history then streams live events |
| POST | `/api/v1/sessions/:id/events` | Internal — agents POST events here |
| POST | `/api/v1/sessions/:id/message` | User sends mid-session free-text guidance |
| POST | `/api/v1/sessions/:id/confirm-features` | User confirms feature list + optional instruction → Phase 2 |

### Documents

| Method | Path | Description |
|---|---|---|
| POST | `/api/v1/documents/` | Save approved document (called by orchestrator) |
| GET | `/api/v1/documents/project/:id` | List docs for a project |
| GET | `/api/v1/documents/:id` | Get a single document |
| PATCH | `/api/v1/documents/:id` | Save human-edited content — old content pushed to `versions[]` |
| POST | `/api/v1/documents/:id/reset` | Restore most recent previous version from `versions[]` |
| PATCH | `/api/v1/documents/:id/approve` | Human-approve a document |

### Dashboard

| Method | Path | Description |
|---|---|---|
| GET | `/api/v1/dashboard/stats` | Aggregated stats (partially wired) |

## Project Status State Machine

```
PENDING
  └─ SCANNING          onboarding agent running
       └─ READY         onboarding complete — project usable

READY
  └─ DISCOVERING        Phase 1 running (feature discovery)
       └─ AWAITING_CONFIRMATION   Phase 1 done — waiting for user to confirm feature list
            └─ GENERATING         Phase 2 running (Generator→Critic loop)
                 └─ READY         Phase 2 done — docs saved

Any stage → ERROR      unrecoverable failure
```

## MongoDB Collections

**Database:** `scribe`

### `projects`
Full project config + agent output. Key fields:
```json
{
  "_id": "short-uuid",
  "name": "string",
  "repos": [{ "url": "string", "branch": "string" }],
  "confluence_sources": [{ "url": "string", "space_key": "string", "space_name": "string" }],
  "jira_url": "string",
  "tech_badges": [{ "label": "string", "cls": "string" }],
  "status": "PENDING | SCANNING | READY | DISCOVERING | AWAITING_CONFIRMATION | GENERATING | ERROR",
  "feature_manifest": [{ "feature": "string", "description": "string", "repos": [], "key_files": [], "jira_epics": [] }],
  "features": ["string"],
  "agent_summary": "string",
  "docs_count": 0,
  "created_at": "ISO8601",
  "last_generated": "ISO8601"
}
```

### `sessions`
One document per generation run:
```json
{
  "_id": "run_YYYYMMDD_HHMMSS_projectId",
  "project_id": "string",
  "depth": "overview | standard | detailed",
  "discovery_mode": "auto | jira-first | code-first",
  "status": "discovering | awaiting_confirmation | generating | completed | error",
  "user_instruction": "string",
  "created_at": "ISO8601"
}
```

### `agent_events`
One document per SSE event emitted by any agent.

### `documents`
One document per feature doc generated by Phase 2.
```json
{
  "_id": "short-uuid",
  "project_id": "string",
  "session_id": "string",
  "feature": "string",
  "content": "string (Markdown)",
  "depth": "overview | standard | detailed",
  "approved": false,
  "versions": [
    { "content": "string (previous Markdown)", "saved_at": "ISO8601" }
  ],
  "generated_at": "ISO8601"
}
```

`versions[]` is appended every time a human edits the document via the AI Document Editor panel. `POST /:id/reset` pops the last entry and restores it as the current content.

## SSE Architecture

Agents POST events to `POST /api/v1/sessions/:id/events`.
scribe-api stores them in `agent_events` and pushes them to an in-memory `asyncio.Queue` keyed by `session_id`.
`GET /api/v1/sessions/:id/stream` replays historical events from MongoDB on connect, then streams new events from the queue.
When a `completed` or `error` event arrives the stream closes cleanly.

## Key Files

| File | Purpose |
|---|---|
| `app/main.py` | App factory, CORS, router registration — docs prefix is `/api/v1/documents` |
| `app/database.py` | Motor client, collection accessors |
| `app/routers/projects.py` | Project CRUD + validation endpoints |
| `app/routers/sessions.py` | Session management, SSE, confirm-features |
| `app/routers/docs.py` | Document CRUD + versioning (PATCH save, POST reset, PATCH approve) |
| `app/services/project_service.py` | Business logic — GitHub/Confluence validation, trigger agents |
| `app/schemas/project.py` | Pydantic schemas — ProjectCreate, ProjectUpdate, ProjectResponse, FeatureItem |
| `seed_doc.py` | One-time script — inserts a demo document for the first project in MongoDB |
